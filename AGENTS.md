# AGENTS.md

For coding agents working in this repository. The rules are the same for
people and agents, and they live in the files below; this file adds none.

- Before you commit, push or open a pull request, read
  [CONTRIBUTING.md](CONTRIBUTING.md).
- Before you write code or docs, read [docs/style.md](docs/style.md); before
  you add a test, [docs/testing.md](docs/testing.md).
- The README's [Develop section](README.md#develop) lists the commands that
  check a change.
- [ARCHITECTURE.md](ARCHITECTURE.md) has the codemap and the invariants.
