# Seam

Seam is a Rust framework for audio plugins. A plugin is to declare a parameter
once, in Rust, and have it automation-correct, undo-clean, MIDI-learnable,
persisted, and reachable from a React page as a typed thing. VST3 is to see it
natively, and AU, AAX and hosting through a generic JUCE adapter driven by a
generated header.

**Status:** pre-release, and not yet usable for a plugin.
